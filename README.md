# 🤖 SimpleVPN

**SimpleVPN** — Telegram-бот для быстрого и удобного подключения пользователей к прокси-серверу,
управляемому через **x-ui панель**.

Бот создан как демонстрация технических навыков (портфолио),  
но при этом полностью пригоден для использования обычными пользователями.

🔗 Telegram: [@SimpleVPN_ProxyBot](https://t.me/SimpleVPN_ProxyBot)

---

## 🚀 Возможности

- 🔐 Подключение пользователей к прокси через x-ui
- 💳 Ручное подтверждение оплаты подписки
- 📊 Отображение статистики трафика пользователя
- 🖥 Инструкции по установке:
  - Windows
  - Android
  - iOS
- ⛔ Автоматическое отключение пользователей при неоплате подписки
- ⏰ Ежедневные напоминания об оплате:
  - начиная с **7-го дня**
  - до окончания подписки
- 💬 Общение с поддержкой прямо внутри бота

---

## 🧭 Команды бота

### Пользовательские команды
- `/start` — перезапуск бота
- `/profile` — открыть профиль пользователя
- `/key` — получить ключ активации (для ПК)
- `/support` — связь с поддержкой

### Административные команды
- `/ser_expiryTime` — установить время до истечения подписки *(только для администратора)*

## 💻 Установка на ПК (особенность проекта)

Для упрощения подключения пользователей на ПК был реализован отдельный механизм:

- Создан **форк Nekoray**
- Форк упакован в `installer.py`
- Установщик:
  - автоматически устанавливает Nekoray
  - загружает конфигурации прокси
- Для работы установщика требуется **ключ активации**, получаемый командой `/key`

Этот подход позволяет пользователю подключиться к прокси **без ручной настройки**.
